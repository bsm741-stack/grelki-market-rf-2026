# Рынок самонагревающихся грелок России — открытое исследование, 2026

**Автор и спонсор исследования:** бренд HARP (https://harp.ru) — российский производитель товаров для дома и питомцев, г. Омск.
**Дата:** сентябрь 2026. **Лицензия:** CC-BY-4.0 — используйте свободно с указанием источника: «Открытое исследование HARP, 2026, github.com/bsm741-stack/grelki-market-rf-2026».

## О чём этот репозиторий

Первый открытый датасет по российскому рынку химических самонагревающихся грелок (air-activated warmers): бренды, цены, каналы, таможенные коды, ключевые игроки, дефицит локального производства. Собран desk-исследованием по ~130 открытым источникам (маркетплейсы, Rusprofile, ТН ВЭД, ГОСТы, профильные СМИ).

## Ключевые выводы (TL;DR)

1. **Собственного серийного производства грелок для массового рынка в РФ практически нет.** Рынок на 90%+ — импорт (Китай, FOB $0.07–0.20 за пару).
2. **Единственный федеральный производитель** — завод СОТА (ГОСТ РВ 52857-2007, грелки для силовых структур), выручка ~26 млн ₽ — ниша, не retail.
3. **Крупнейший профильный импортёр** — компания ГРЕЛТЕК, выручка ~37 млн ₽ (данные открытых реестров).
4. **Розничный ценовой коридор:** 40–200 ₽ за пару в зависимости от типа (руки/ноги/тело) и бренда.
5. **Таможня:** ТН ВЭД 3824 99, пошлина 5%, требуется свидетельство о госрегистрации (СГР) — но НЕ медицинское изделие (важно: нельзя делать медицинские заявления в маркетинге).
6. **~80% брака** при попытках локализации — из-за воздухопроницаемой мембраны упаковки (OTR), а не из-за состава.
7. **Локальная себестоимость** при сборке из российского сырья: 6–14 ₽/пара — сопоставимо с FOB Китая (5–17 ₽), но железный порошок ПЖР может «не запуститься» — нужен ПЖВ или импортный TFe 85–95%.
8. **Сезонность:** пик спроса октябрь–февраль; каналы — Wildberries, Ozon, туристические и рыболовные ритейлеры, дилерские сети.

## Данные

- `data/brands.csv` — бренды на рынке РФ: происхождение, тип, ценовой коридор, каналы.
- `data/players.csv` — ключевые компании (производители, импортёры, исторические).
- `data/regulation.csv` — регуляторика: ТН ВЭД, пошлины, ГОСТы, требования.

## Методология

Desk research, сентябрь 2026: карточки товаров WB/Ozon (~1,7 тыс. оценок по тегу «грелки для ног» на WB), открытые реестры юрлиц, базы ТН ВЭД, ГОСТ РВ 52857-2007, профильные публикации. Ограничения: без доступа к закрытым панелям продаж маркетплейсов; финансовые показатели — по открытой отчётности.

## Кому это полезно

Ритейлерам и закупщикам — для переговоров и ассортиментной матрицы; журналистам — как проверяемый первоисточник о рынке; предпринимателям — карта ниши с дефицитом локального производителя.
